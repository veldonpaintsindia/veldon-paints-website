QUICK START (Do this first):
================================================================================

1. Open Terminal and navigate to project:
   cd "/Users/nikhil/Desktop/Veldon Paints/veldon-paints-website"

2. Install dependencies:
   npm install

3. Create environment file:
   cp .env.example .env.local

4. Get Formspree ID (for contact form):
   - Visit: https://formspree.io
   - Sign up (free)
   - Create a new form
   - Copy your form ID (looks like: f/abc123def)
   - Edit .env.local and add:
     NEXT_PUBLIC_FORMSPREE_ID=f/your_id_here

5. Start development server:
   npm run dev

6. Open in browser:
   http://localhost:3000

That's it! Your website is ready.

TO DEPLOY:
================================================================================

Easiest: Vercel (made by Next.js team)
  1. Push code to GitHub/GitLab/Bitbucket
  2. Go to vercel.com
  3. Click "New Project" and import repository
  4. Add NEXT_PUBLIC_FORMSPREE_ID to environment variables
  5. Click "Deploy"

Other options:
  - Netlify
  - AWS Amplify
  - Railway
  - Docker
  See DEPLOYMENT.md for detailed instructions

TROUBLESHOOTING:
================================================================================

If npm install fails:
  rm -rf node_modules
  npm install

If port 3000 is in use:
  npm run dev -- -p 3001

If styles don't work:
  npm run build

If form doesn't send:
  Check Formspree ID in .env.local
  Verify format: f/xxxxxxxx
  Test at formspree.io directly

If cursor doesn't animate:
  Check browser console for errors (F12)
  Clear cache and reload
